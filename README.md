# 北大附小智能阅读推荐

面向小学生和家长的手机端 H5 阅读推荐页面。

访问链接：

https://lmissd.github.io/library_pku/

## 使用方式

家长或小朋友直接打开上面的链接即可使用，不需要填写接口地址、Token、访问码，也不需要启动本机服务。

页面入口：

- 小朋友端：输入姓名、年级、阅读兴趣和阅读历史，获取三层图书推荐，手动选择一本书，读完后完成阅读小问答。
- 家长端：查看孩子选择的书、阅读路径、阅读反馈、可沟通的话术、阅读画像和下一本建议。

## 当前说明

页面已经隐藏所有技术配置项，只保留孩子和家长需要填写的阅读信息。

当前临时跑通版本默认使用内置本地书库，继续完成推荐、阅读提问和阅读反馈，避免孩子使用时直接报错。

页面代码中保留了线上工作流地址，后续 Coze 入口处理好鉴权后，可以再切回线上工作流优先。

注意：当前 Coze 工作流地址匿名访问会返回 `401 Unauthorized`。长期正式版本建议提供一个不暴露 Token 的公网入口，例如开放工作流免鉴权访问，或提供一个安全代理服务。

## 技术

- 单文件 H5：`index.html`
- 纯 HTML + CSS + JavaScript
- GitHub Pages 静态托管
- 临时内置本地书库兜底
