# 北大附小图书馆・智能阅读伙伴

一个面向小学生的手机端 H5 阅读推荐演示应用。

## 功能简介

- 支持“小朋友端”和“家长 / 老师端”自主选择。
- 小朋友端输入姓名、年级、想看的书和可选借阅记录。
- 小朋友端根据内置书单知识库，推荐三层阅读：
  - 兴趣入口书
  - 桥梁书
  - 经典 / 拓展书
- 小朋友端只展示适合孩子看的推荐话术、鼓励语和书籍卡片。
- 家长 / 老师端输入孩子姓名和年级，查看孩子的阅读记录、推荐阅读路径、家长建议和追问问题。
- 不依赖后端接口，手机浏览器打开即可体验。

## 数据记录说明

当前是 GitHub Pages 前期测试版，没有独立后端数据库。

- 小朋友端每次点击“帮我找书”，会把虚拟姓名、年级、需求、借阅记录和推荐结果保存到当前浏览器的 `localStorage`。
- 家长 / 老师端可以在同一浏览器里按虚拟姓名和年级查询这些测试记录。
- 不同手机、不同浏览器之间不会自动同步记录。
- 正式集中收集全班或全校数据时，需要再接入后端接口和数据库。

## 技术说明

- 纯 `HTML + CSS + JavaScript`
- 单文件主应用：`index.html`
- 无 React、Vue 或其他前端框架
- 内置本地书单数据，适合快速演示和用户沟通
- 移动端优先设计，适配手机屏幕
