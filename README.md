# 北大附小智能阅读推荐

面向小学生和家长的手机端 H5 阅读推荐页面。

访问链接：

https://lmissd.github.io/library_pku/

## 使用方式

家长或小朋友直接打开上面的链接即可使用，不需要填写接口地址、Token、访问码，也不需要启动本机服务。

页面流程：

- 输入姓名、年级、阅读兴趣和阅读历史
- 获取三层图书推荐：
  - 兴趣入口书
  - 桥梁书
  - 经典 / 拓展书
- 点击“我已读完📖”
- 回答阅读小问题
- 查看阅读反馈、分数、鼓励语和下一本推荐

## 当前说明

页面已经隐藏所有技术配置项，只保留孩子和家长需要填写的阅读信息。

注意：当前工作流地址匿名访问会返回 `401 Unauthorized`。如果要让 GitHub Pages 链接真正做到“点开即完整使用”，后端需要提供一个不暴露 Token 的公网入口，例如开放工作流免鉴权访问，或提供一个安全代理服务。

## 技术

- 单文件 H5：`index.html`
- 纯 HTML + CSS + JavaScript
