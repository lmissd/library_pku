# 北大附小图书馆・智能阅读伙伴

一个面向小学生的手机端 H5 阅读推荐演示应用。

## 功能简介

- 孩子输入姓名、年级、想看的书和可选借阅记录。
- 页面根据内置书单知识库，推荐三层阅读路径：
  - 兴趣入口书
  - 桥梁书
  - 经典 / 拓展书
- 自动生成适合孩子阅读的鼓励语、阅读路径、家长建议和追问问题。
- 不依赖后端接口，手机浏览器打开即可体验。

## 技术说明

- 纯 `HTML + CSS + JavaScript`
- 单文件主应用：`index.html`
- 无 React、Vue 或其他前端框架
- 内置本地书单数据，适合快速演示和用户沟通
- 移动端优先设计，适配手机屏幕

## 使用方式

直接打开 `index.html`，或部署到任意静态网站服务后访问公开链接。
